# Roadmap: Passenger Rights AI (frontend)

Пошаговый план разработки сайта платформы **Passenger Rights AI** от нуля до работающего продукта.

**Стек:** React / Next.js, SSR + SSG, адаптивный дизайн  
**Дизайн-референс:** [Flighty](https://flighty.com/)  
**Основной язык:** английский  
**Доп. языки:** испанский, казахский, узбекский, русский  
**Локальный порт:** `http://localhost:3001`

**Продуктовая идея:** понять, насколько вероятны задержка, отмена рейса или пропуск стыковки — «кредитный рейтинг» для рейса.

**Вне скоупа на данном этапе:** тестирование (unit, e2e, visual regression), CI/CD и деплой.

**Доп. модуль:** [ICAO FPL Validator — roadmap](./roadmap-fpl-validator.md)
